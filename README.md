# Track My Puppy 🐾

A React Native mobile app for logging and tracking puppy care activities, 
built with Expo.

## Features
- **Home** — [quick overview / dashboard of recent activity]
- **Data tracking** — log [feeding, walks, potty breaks, training, weight — adjust to what it actually tracks]
- **Persistent storage** — saved locally so your data isn't lost between sessions
- **About** — [app info / how-to]

## Tech Stack
- React Native
- Expo
- React Context API for state management (ValueContext.js)
- Local storage (Storage.js)

## Getting Started
1. Clone the repo
 - git clone https://github.com/neha-kalakuntla/Track-My-Puppy.git
 - cd Track-My-Puppy

2. Install dependencies
 - npm install

3. Run the app
- npx expo start
